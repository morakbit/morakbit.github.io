Cinema Duet Uploader 개인정보처리방침

Cinema Duet Uploader(이하 '앱')는 MORAKBIT STUDIO(이하 '개발자')가 운영하는 YouTube 채널 Cinema Duet(@cinemaduet)에 개발자가 만든 영상을 올리기 위해, 개발자 본인의 컴퓨터에서만 쓰는 도구입니다. 다른 사람에게 배포하거나 제공하지 않습니다.

1. 사용하는 Google 사용자 데이터

앱은 개발자 본인의 Google 계정으로 로그인한 뒤 YouTube Data API를 통해 다음 일만 합니다.

  • 개발자의 채널에 영상 올리기
  • 올린 영상의 제목, 설명, 태그, 썸네일, 재생목록, 공개 예약 시간 같은 정보 설정

앱은 이 일에 필요한 YouTube 권한만 요청하며, 다른 사람의 계정이나 데이터에는 접근하지 않습니다.

2. 저장과 전송

로그인 후 받은 인증 정보(토큰)는 개발자 컴퓨터에만 저장됩니다. 앱에는 서버가 없으며, 어떤 데이터도 개발자 컴퓨터와 Google 밖으로 보내지 않습니다.

3. 제3자 제공

개발자는 Google 사용자 데이터를 제3자에게 제공하거나 판매하지 않으며, 광고나 분석에 쓰지 않습니다. 앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 옮기는 일은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. YouTube와 Google의 약관

앱은 YouTube API 서비스를 사용합니다. 이용에는 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

5. 권한 철회

앱의 계정 접근 권한은 Google 계정의 서드 파티 연결에서 언제든지 해제할 수 있습니다.

Cinema Duet Uploader Privacy Policy

Cinema Duet Uploader (the "App") is a tool that MORAKBIT STUDIO (the "Developer") runs only on the Developer's own computer to upload the Developer's own videos to the YouTube channel Cinema Duet (@cinemaduet). It is not distributed or offered to anyone else.

1. Google user data the App uses

After the Developer signs in with the Developer's own Google account, the App uses the YouTube Data API only to:

  • upload videos to the Developer's channel
  • set details of those videos, such as title, description, tags, thumbnail, playlist and scheduled publish time

The App requests only the YouTube permissions needed for this and does not access any other person's account or data.

2. Storage and transfer

The sign-in credentials (tokens) are stored only on the Developer's computer. The App has no server and sends no data anywhere other than between the Developer's computer and Google.

3. Sharing

The Developer does not share or sell Google user data to third parties and does not use it for advertising or analytics. The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. YouTube and Google terms

The App uses YouTube API Services. The YouTube Terms of Service and the Google Privacy Policy also apply.

5. Revoking access

Access can be revoked at any time on the Google Account third-party connections page.

6. Contact

Please use the contact on the MORAKBIT STUDIO home page.

7. Changes

If this policy changes, the updated text and effective date will be posted on this page.
